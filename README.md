# MOKKA — сайт кофейни (портфолио)

Многостраничный адаптивный концепт сайта кофейни в Смоленске на React + Vite.

## Что внутри
- Главная страница с промо-блоком и популярными позициями.
- Меню с категориями, поиском и добавлением в корзину.
- Корзина с изменением количества и расчётом суммы.
- Оформление демо-заказа с проверкой полей и экраном подтверждения.
- Страница «О кофейне».
- Контакты с картой OpenStreetMap и адресом-заглушкой в Смоленске.
- Адаптивная мобильная навигация, анимации, сохранение корзины в localStorage.

## Запуск на Windows
1. Установи Node.js LTS: https://nodejs.org/
2. Распакуй архив и открой папку `smolensk-cafe-portfolio` в VS Code.
3. Открой терминал VS Code: **Терминал → Создать терминал**.
4. Выполни:
   ```bash
   npm install
   npm run dev
   ```
5. Открой адрес, который появится в терминале (обычно http://localhost:5173).

## Сборка
```bash
npm run build
npm run preview
```
Готовая production-сборка появится в `dist/`.

## Важно перед публикацией
Это демонстрационный проект для портфолио, не настоящий сервис доставки. Заказы никуда не отправляются: форма показывает подтверждение в браузере. Для реального бизнеса потребуется сервер/API, база данных и подключение к уведомлениям.
Адрес и телефон — демонстрационные, замени их на реальные. Фото загружаются с Unsplash, карта — OpenStreetMap; для офлайн-работы нужны локальные изображения.
